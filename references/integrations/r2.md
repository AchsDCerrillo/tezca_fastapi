# Cloudflare R2 (`app/core/r2.py`)

R2 is S3-compatible, so it reuses the `S3Storage` class from `app/core/s3.py`. If `s3.py` doesn't exist yet, create it first, following `s3.md`; only the class is needed, not the S3 settings.

**requirements.txt:** `aioboto3==15.5.0`

**Settings and `.env.example`:**
```python
# Cloudflare R2
r2_account_id: str = ""
r2_access_key_id: str = ""
r2_secret_access_key: str = ""
r2_bucket: str = ""
r2_public_base_url: str | None = None   # custom domain or r2.dev URL, if the bucket is public

@property
def r2_endpoint_url(self) -> str:
    return f"https://{self.r2_account_id}.r2.cloudflarestorage.com"
```
```
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET=
R2_PUBLIC_BASE_URL=
```

**Module:**
```python
from functools import lru_cache

from app.core.config import get_settings
from app.core.s3 import S3Storage


class R2Storage(S3Storage):
    def __init__(self, *, public_base_url: str | None = None, **kwargs):
        super().__init__(**kwargs)
        self.public_base_url = public_base_url

    def public_url(self, key: str) -> str:
        if not self.public_base_url:
            raise ValueError("R2_PUBLIC_BASE_URL is not configured; use presigned_get_url instead")
        return f"{self.public_base_url.rstrip('/')}/{key}"


@lru_cache
def get_r2_storage() -> R2Storage:
    settings = get_settings()
    return R2Storage(
        bucket=settings.r2_bucket,
        region="auto",
        endpoint_url=settings.r2_endpoint_url,
        access_key_id=settings.r2_access_key_id,
        secret_access_key=settings.r2_secret_access_key,
        public_base_url=settings.r2_public_base_url,
    )
```
**Notes:**
- R2 ignores ACLs and storage classes.
- Presigned URLs work for GET and PUT.
- Create the API token in the Cloudflare dashboard with **Object Read & Write** scoped to the bucket.
